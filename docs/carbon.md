# siesta-carbon

Reference implementation wrapping [nesbot/carbon](https://carbon.nesbot.com/).

## Factories

`now`, `parse`, `createFromFormat`, `createFromDate`, `yesterday`, `tomorrow`

## Methods

`addWeeks`, `addDays`, `format`, `diffInDays`, `isWeekend`, `startOfWeek`, `endOfMonth`, `setTimezone`, and more.

## Config

- `defaultTimezone` (default: UTC)
- `locale` (default: en)
- `weekStartsAt` (default: 1 = Monday)

See [agent scenarios](https://github.com/siesta-ai-protocol/siesta/blob/main/examples/calendar/agent-scenarios.md).
